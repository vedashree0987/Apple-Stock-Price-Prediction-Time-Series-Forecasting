# Apple Stock Price Prediction

A machine learning project that predicts Apple's stock closing prices for the next 30 trading sessions using historical stock data.

## Features

- Historical stock price visualization
- Interactive date range selection
- 30-session stock price forecasting
- Comparison of historical and predicted prices
- Forecast results in tabular format
- Download predictions as CSV

## Machine Learning Models

1. ARIMA
2. SARIMA
3. Random Forest
4. XGBoost
5. GRU

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Statsmodels
- TensorFlow
- XGBoost
- Streamlit
- Plotly

## Installation

Clone the repository:

    git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project folder:

    cd Apple-Stock-Price-Prediction

Create a virtual environment:

    python -m venv venv

Activate it:

    venv\Scripts\activate

Install dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Dataset

Historical Apple stock data from 2012 to 2019.
